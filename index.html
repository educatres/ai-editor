操作說明
  1. 選擇 AI 供應商，輸入 API Key，確認 Endpoint 與模型後按「儲存」。
  2. 按「模式」可選擇全文潤飾、只潤飾 {{ }}，或提供全文上下文但只潤飾 {{ }}。
  3. 局部潤飾時，以 {{ 要潤飾的文字 }} 標記內容，再按「潤飾」。
  4. 若大括號只作為一般文字，局部潤飾時可使用 \{ 與 \}。
  5. Search 可持續搜尋上一個或下一個結果；按「關閉」才會隱藏搜尋列。
  6. System prompt 已整合在「模式」視窗，可選擇取代原內容，或以分隔線追加範本。
  7. 「換行」會依網頁寬度自動換行；複製與下載不會改變原始文字。

文章、API 與各項設定會保存在本瀏覽器的 LocalStorage。
